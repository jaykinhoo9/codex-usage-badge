# 上下文圆环与验证边界

常态只有圆环，位于当前可见 composer 的模型选择框左侧。悬停或键盘聚焦可查看最近一次模型请求的统计；输入中的文字不参与实时逐字计数。有效 0% 使用绿环，无可靠统计使用灰环。

## 来源与兼容性

只读查询最新版本 state 数据库的会话 ID 与 rollout_path，不回退旧账号数据库。日志首读最多 4 MiB，后续共用文件游标增量读取；单条待解析记录最多 256 KiB。可以跳过具有已确认日志封装的超长正文记录，超长统计或无法确认类型的记录则清除来源证据。没有在读取范围内取得请求上下文时保持未知。

当前客户端的 `token_usage_record` 含明确的 thread、turn、response 身份。读取器使用递增 ordinal、turn_context 的模型与请求上下文，将该记录的完整用量字段与随后 token_count 的 last/total 字段匹配。只有完整匹配才采用后者的实际上下文容量；缺少身份、重复来源、指纹冲突、交错未配对来源或最新统计非法时显示未知。观察到模型切换后，旧请求上下文不再接受，包括 A→B→A；DOM 重挂载保留已观察到的切换基线。

该适配依赖客户端私有 React props、日志封装及统计记录格式。旧版本没有必要来源字段时不会仅凭模型名或时间猜归属。远程会话不查本机数据库。不会修改用户的原生上下文用量设置；同一 composer 的原生环实际可见时插件隐藏，原生隐藏后恢复。当前原生语义识别覆盖中文和英文标签，其他语言及后续客户端版本未验证。

## 验证记录（2026-11-01）

- 自动化：格式化数值边界、动态容量、缓存输入不重复相加；只读 SQLite 查询、无旧库回退、请求来源匹配、A→B→A、交错、重放、半行、UTF-8 分片、超长记录、截断、替换、读取失败与恢复、有界读取和跨窗口游标去重。
- 自动化 UI：明暗主题、窄窗口、长模型名、悬停延迟、焦点、失焦、Escape、reduced motion、原生环显示/隐藏、多个 composer/窗口、旧异步结果拒收、心跳失联与恢复、重复注入、克隆重挂载与销毁。安装器卸载链路也包含新圆环清理。
- 真实客户端：Windows 包 26.1027.3384.0，已从当前可见本地 composer 取得一致的 host/thread/model，使用真实日志元数据关联到有效请求统计并显示。实测交互区 24×24 px、SVG 14×14 px、与模型控件间距 6 px、垂直中心一致；聚焦后上方浮层可见。没有把用户日志复制到测试夹具。
- 未完成的实机覆盖：完整的多窗口／模型切换后恢复、明暗主题切换、原生设置启用后的去重，以及实际硬件键盘交互。CDP 键盘派发未在目标窗口收到事件，后续调试端口连接被拒绝；隔离 Chromium 的键盘测试通过，不能替代这项实机证据。没有为此重启客户端或更改用户设置。

统计仅在本机处理。读取日志字节可能接触正文，但只提取统计和必要请求元数据；不持久化、记录或上传正文、原始日志行、私人路径和凭据，详见 [隐私与安全](../SECURITY.md)。
